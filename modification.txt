Critical Architectural Conflicts to Resolve

| Conflict                         | Current Code                   | Plan Requirement                                           | Recommended Resolution                                                                                               |
| -------------------------------- | ------------------------------ | ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Register endpoint dual-use**   | Always creates `role: 'user'`  | Same endpoint must create `buyer` OR `user`                | Accept `role` in body, validate against enum `['user','buyer']`, default to `'user'`                                 |
| **Admin creation**               | No admin creation flow         | Only `superAdmin` creates `admin` with credentials         | New `superAdmin` service generates random temp password, admin must change on first login (or use `change-password`) |
| **Order delivery details**       | Basic structure in Order model | Rich nested object (address, timeSlot, deliveryType, etc.) | Embed full `deliveryDetails` in Order model as shown in plan; auto-fill from `BuyerProfile` at checkout              |
| **Guest cart → user cart merge** | No cart system exists          | On login, guest cart merges into user cart                 | Implement in `cart.service.js` merge logic: union by productId, sum quantities, keep latest price snapshot           |
| **Deactivated admin login**      | Only checks `isBlocked`        | Must also check `isActive`                                 | Add `checkActive` middleware after `verifyJWT` on protected routes, or bake it into `verifyJWT`                      |
| **Buyer vs User role**           | No `buyer` role exists         | Buyers are distinct from `user` (farmer candidate)         | Add `'buyer'` to enum; ensure `isUser` middleware still works for farmer requests (only `'user'` role)               |
