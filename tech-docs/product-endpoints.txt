| Method   | Route                       | Access | Description                                |
| -------- | --------------------------- | ------ | ------------------------------------------ |
| `GET`    | `/api/products`             | Public | Browse products (search, filter, paginate) |
| `GET`    | `/api/products/:id`         | Public | Get single product                         |
| `POST`   | `/api/products`             | Farmer | Create product                             |
| `GET`    | `/api/products/my-products` | Farmer | List my products                           |
| `PUT`    | `/api/products/:id`         | Farmer | Update my product                          |
| `DELETE` | `/api/products/:id`         | Farmer | Delete my product                          |

The important check is:

product.farmerId === req.user._id

If yes → update.

If no → 403 Forbidden.
